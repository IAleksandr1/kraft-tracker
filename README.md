# ЖУРНАЛ — заметки + трекер трат в Google Таблице

Минималистичный сайт на Next.js: пишешь заметку, выбираешь тему, сумма
распознаётся автоматически (или вводится вручную) — запись улетает в
Google Таблицу и сразу показывается в трекере по дням.

## 1. Установка и запуск локально

```bash
npm install
npm run dev
```

Открой http://localhost:3000

Без переменных окружения (шаг 2) сайт запустится, форма будет работать,
но при сохранении будет ошибка — Google Таблица ещё не подключена.

## 2. Настройка Google Таблицы (пошагово, с нуля)

### Шаг 1. Создай саму таблицу
1. Зайди на https://sheets.google.com и создай новую таблицу.
2. Переименуй первый лист в `Entries` (важно — именно так, с большой буквы).
3. В первую строку впиши заголовки: `Дата | Категория | Заметка | Сумма`.
4. Скопируй ID таблицы — это часть ссылки между `/d/` и `/edit`:
   ```
   https://docs.google.com/spreadsheets/d/ЭТО_И_ЕСТЬ_ID/edit
   ```

### Шаг 2. Создай проект в Google Cloud
1. Зайди на https://console.cloud.google.com/
2. Вверху создай новый проект (или выбери существующий).

### Шаг 3. Включи Google Sheets API
1. В меню слева: **APIs & Services → Library**.
2. Найди «Google Sheets API» → нажми **Enable**.

### Шаг 4. Создай service account (служебный аккаунт)
1. **APIs & Services → Credentials → Create Credentials → Service account**.
2. Дай любое имя, например `kraft-tracker`, нажми **Create and Continue**,
   затем **Done** (роли можно не назначать).
3. Открой созданный service account → вкладка **Keys** → **Add Key →
   Create new key → JSON**. Файл скачается автоматически — сохрани его.

### Шаг 5. Дай сервисному аккаунту доступ к таблице
1. Открой скачанный JSON-файл, найди в нём поле `client_email`
   (выглядит как `kraft-tracker@твой-проект.iam.gserviceaccount.com`).
2. Вернись в свою Google Таблицу → кнопка **Настройки доступа /
   Share** → вставь этот email → дай права **Редактор** → сохрани.

### Шаг 6. Заполни переменные окружения
Скопируй `.env.example` в `.env.local`:

```bash
cp .env.example .env.local
```

Из JSON-файла возьми:
- `client_email` → вставь в `GOOGLE_SERVICE_ACCOUNT_EMAIL`
- `private_key` → вставь в `GOOGLE_PRIVATE_KEY` **целиком, в кавычках**,
  переносы строк там останутся как `\n` — это нормально, ничего не меняй.

ID таблицы из шага 1 → в `GOOGLE_SHEET_ID`.

Получится примерно так:

```
GOOGLE_SERVICE_ACCOUNT_EMAIL=kraft-tracker@твой-проект.iam.gserviceaccount.com
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIEv...\n-----END PRIVATE KEY-----\n"
GOOGLE_SHEET_ID=1a2B3c4D5e6F7g8H9i0J...
```

Перезапусти `npm run dev` — готово, записи начнут падать в таблицу.

## 3. Деплой (например, на Vercel)

1. Залей проект на GitHub.
2. Импортируй репозиторий в https://vercel.com
3. В настройках проекта на Vercel добавь те же три переменные окружения
   (Settings → Environment Variables).
4. Deploy.

## Структура проекта

```
app/
  page.tsx              — главная страница, три вкладки (Главная / Заметки / Привычки)
  layout.tsx            — шрифты и общий фон
  api/entries/route.ts  — API: чтение/запись в Google Таблицу (только вкладка «Заметки»)
components/
  Home.tsx               — главный экран с вступительным текстом и переходами на другие вкладки
  NoteForm.tsx           — форма заметки, автоопределение суммы, темы
  Ledger.tsx             — таблица-трекер по дням (данные из Google Таблицы)
  HabitTracker.tsx       — трекер привычек (данные только в браузере)
lib/
  sheets.ts              — работа с Google Sheets API
  parseAmount.ts          — распознавание суммы из текста
  categories.ts           — список тем + свои темы (хранятся в браузере)
  habits.ts               — привычки и отметки по дням (localStorage, без Google Sheets)
```

## Про вкладки
- **Главная** — вступительный экран с коротким текстом и двумя карточками-переходами
  на «Заметки» и «Привычки». Ничего не хранит и не отправляет.
- **Заметки** — заметки с темами и суммами уходят в Google Таблицу (настройка — раздел 2 выше).
  Без переменных окружения эта вкладка будет показывать ошибку при сохранении.
- **Привычки** — работает сразу, без какой-либо настройки. Все данные хранятся
  в `localStorage` браузера, то есть только на этом устройстве/в этом браузере.
  Если открыть сайт с другого телефона или очистить данные сайта в браузере —
  привычки не сохранятся.
